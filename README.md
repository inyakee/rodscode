# Rodscode — Rodney C. Gonzales

Personal résumé and portfolio using React 19, Vite, Tailwind CSS 4, and Lucide React. The warm cream, espresso, amber, and moss design is retained from the original portal, with content personalized from Rodney's existing résumé.

## Run

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The production build is in `dist/`.

## Content

Edit `src/main.jsx` for professional experience, skills, education, certifications, and contact details. The original résumé and portrait are in `public/`. The profile uses the dates listed in the résumé, including both iQor periods, and does not assume continuing employment after May 2026.

Selected work cards summarize documented teaching, support, and mentorship responsibilities. They are not fabricated software case studies. Add individual development projects and repository links when available.

The previous sample metrics, proficiency percentages, fit simulator, quiz, sample code downloads, and simulated calendar have been removed. Résumé downloads serve the real PDF. Email and telephone links open the visitor's corresponding application; the website does not send messages itself.

## Accessibility

Semantic landmarks, accessible navigation and filter buttons, keyboard-operable experience controls, dialog focus management, Escape support, live experience details, a skip link, and reduced-motion support.
